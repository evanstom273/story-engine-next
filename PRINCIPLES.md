# Principles

## The author is in control

The player owns their protagonist.

## Canon is sacred

Continuity is prioritised over novelty.

## Trust valid AI output

If generated output is valid, preserve it verbatim.

## Single source of truth

Every domain has one owner.

## Rendering is read-only

Rendering never mutates stored transcript content.

## Story first

Features must justify themselves by improving writing.

## Offline-friendly, cloud-backed

Use local cache with Supabase synchronisation.
